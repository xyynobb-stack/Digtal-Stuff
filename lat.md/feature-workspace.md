# Feature workspace

“功能区”在计划任务之后提供可扩展的本地文档工具入口，首批能力包括 OCR 和合同比对，并保持普通应用启动不加载推理引擎。

## Navigation and execution boundary

功能区是独立的侧边栏页面；渲染进程只选择文件和展示结果，文件校验、子进程调用与模型请求都经由受限 preload IPC 交给主进程。

## Offline dependency packaging

OCR 依赖必须安装进受管理的离线 Agent 虚拟环境，并由 Runtime 归档校验和 release 工作流导入检查共同保证，禁止在用户首次运行时联网安装。

RapidOCR 和 ONNX Runtime 仅在 MinerU 不可用且需要本地回退时导入，因此不能加入安装探针或应用冷启动路径；MinerU 权重只部署在服务器，不进入安装包。

## Personal experience skill

岗位经验沉淀复用功能区返回入口，用户填写岗位背景与最多十二个场景，本地确定性生成带场景路由、具体流程、分支、公司特殊做法及逐字段来源的个人技能，不调用模型或推断缺失制度。

表单草稿按 Profile 保留在当前窗口内存，重启不保留未保存草稿；确认后的填写内容持久化为来源快照。预览不安装技能，确认保存后写入当前 Profile 的 `skills/custom/personal-experience/SKILL.md`，使用与侧边栏相同的 Profile 元数据姓名生成“用户名的SKILL”，通过现有刷新事件出现在聊天可选技能中，不自动启用。

主进程检查本地模式、当前 Profile、预览有效期、姓名及磁盘版本；异步读取身份后重新检查，发布阶段无异步间隙。先保存内容寻址的来源快照与旧版备份，再通过临时文件重命名发布 SKILL.md，避免覆盖并发修改或改变员工配置、头像和历史数据。同名但缺失来源快照的技能不会被接管。

场景编辑使用稳定的界面标识，删除采用页面内二次确认，并在提交后聚焦相邻场景，避免原生同步确认框和 DOM 复用破坏文本输入状态。编译器测试覆盖完整字段保留、步骤顺序、来源与缺失输入；存储测试覆盖预览无写入、重新加载、更新备份、账号切换、改名、远程模式及并发覆盖保护；界面测试覆盖返回、草稿隔离、首场景删除后立即输入和确认保存后刷新技能列表。

## OCR

OCR 支持常见图片和 PDF；安装版在本地判断文字页与扫描页，文字层直接提取，扫描页面按受限并发发送至配置的 MinerU 服务，失败时回退本地 RapidOCR。

安装包默认通过出口映射 `183.230.226.81:8086` 连接 MinerU；网关将请求转到宿主机 `8008`，Docker 再转到容器 `8000`。部署环境可通过 `JINGYUAI_MINERU_API_BASE` 覆盖外部地址。

MinerU 的 Markdown 标题和 HTML 表格在 worker 中转为结构化块，再由渲染进程创建安全的原生元素；不可访问的服务端图片路径不会进入界面或复制文本。

### MinerU page routing

PDF 页面根据原生文字量与整页图片覆盖率分流；扫描页以受控 DPI 分批渲染，避免大文档同时驻留全部页面图像，并兼容 MinerU 多版本 Markdown 返回结构。

## Persistent processing history

OCR 与合同比对的成功结果按 Profile 持久化，使用户重启应用后仍可恢复查看，并可独立删除不再需要的记录。

主进程使用用户数据目录中的独立 SQLite 数据库保存结果，列表只读取标题、来源文件名和时间等摘要，用户打开记录时再读取完整结果。界面最多展示最近 100 条；失败任务不写入历史。

历史记录保留 OCR 页、结构化表格、合同结构与精确差异；AI 解读完成后更新对应合同记录，并保留当时的模型标识、分析立场和发送范围。记录不复制原始文件，因此源文件移动或删除后仍能查看既有结果，但不能据此重新执行处理。

## Contract comparison

合同比对先在本地提取 DOCX 或文字型 PDF；扫描 PDF 页面复用 OCR 的 MinerU 分流与本地回退，再生成可复核的差异，AI 解读不能修改精确结果。

### Side-by-side review

结果界面左右连续展示旧版与新版正文、同步滚动并直接标注变化，右侧差异导航支持按类型筛选、搜索和定位；DOCX 表格保留行列、横向合并、纵向合并和列宽比例，并在单元格内标记差异。

桌面宽度下比对区具有固定高度边界，左右合同和右侧差异列表分别滚动；差异列表阻止滚动链传递到功能页，并保留汇总与筛选控件，长结果不会撑高整页。窄屏展开时恢复纵向布局。

合同比对详情顶部提供始终可见的返回功能区入口，切换工具无需离开功能区页面。

长文件名必须保持选择卡片等宽并省略显示，悬停仍可查看全名；布局按功能内容区宽度响应，窄屏自动折叠差异栏，左右合同可在 30% 至 70% 之间拖动或用键盘调整，双击分隔条恢复均分。

### Structured Word tables

DOCX 解析器按正文顺序提取段落和表格，并保留表格列宽、横向合并与纵向合并；左右视图在对应单元格内显示文本级差异。纯删除只标记旧版被删字符，纯新增只标记新版新增字符。

### Deterministic paragraph diff

PDF 视觉行先合并为文本块和自然段；段落对齐关闭自动噪声判断，并为每项差异保留新旧段落序号、正文和相似度，使同一输入得到稳定且可定位的结果。

## Optional AI interpretation

用户可从当前 Profile 有权使用的模型中选择一个模型，只把变化条款发送给它，并选择中立、甲方或乙方立场；输出必须标为辅助分析而非法律意见。
