# v0.7.41 发布说明

本版本修复报告 Skill 重复与旧版契约无法随升级生效的问题，并严格按人力资源、财务分析大纲约束 RAG 报告生成。

## 报告 Skill

- 重写 `hr-analysis-report-rag`，固定资料来源、替代来源、章节结构、表头、生成顺序、缺失项和敏感数据边界。
- 重写 `finance-analysis-report-rag`，固定业务估算口径、成本计算顺序、单位经济模型、风险与行动结构。
- 工作流状态机同步校验两类报告的章节依赖、证据编号和生成顺序。
- 三类报告统一标注品类及跨报告数据接口，最终仍输出 Word 文档。

## Skill 迁移与升级

- 修复旧版 `research/market-report-rag` 被识别成用户 Skill，导致聊天框出现两个同名 Skill 的问题。
- 旧目录不会直接删除，而是迁移至用户目录下的 `skill-backups` 供恢复。
- 三个内置报告 Skill 使用内容版本标记，仅在安装包内容变化时升级一次。
- 升级时先备份旧目录，再原子启用新版本；普通用户自定义 Skill 保持不覆盖。

## 验证

- 报告工作流测试、离线运行时打包测试和桌面端预置内容迁移测试通过。
- TypeScript 类型检查及 `lat check` 通过。
