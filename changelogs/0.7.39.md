# v0.7.39 发布说明

本次发布汇总员工模型协议适配、AIHub 备用线路及桌面运行稳定性改动。

## 模型协议与会话路由

- 根据员工接口的 `api_formats` 同时导入 Chat Completions 和 Responses 模型，保留各自协议与上下文配置。
- 为公司平台建立独立协议路由，初始化、模型切换及会话就绪校验包含协议身份，避免共享地址和密钥时串用配置。
- 公司 Responses 请求使用 `JingYu-Desktop` User-Agent，其他供应商不受影响。

## AIHub 模型兜底

- 为已配置备用密钥的员工档案启用 AIHub `/v1/responses`、`gpt-5.6-terra` 备用线路。
- 主线路 30 秒未收到首个响应事件时尝试兜底；429、502、503、504 及明确模型不可用等错误可直接切换，500 和连接故障先短暂重试。
- 401 鉴权失败可切换；403 仅在明确模型授权不足或账户停用时切换。内容安全拒绝与原因不明的 403 不触发切换。
- 保留部分正文输出保护、用户停止保护及旧请求关闭确认，避免主备请求并发修改同一会话；不改写默认模型，不重放已完成工具。
- 备用密钥通过本机环境文件或员工配置接口下发，不写入源码、YAML 或安装包。

## 桌面运行与提示词

- 在 Execute Code 运行层隐藏 Windows 子进程控制台，覆盖 subprocess 和 os.system 的常见调用路径。
- 将模型可见的身份提示词统一为 JingYu Agent，并迁移精确匹配的旧默认身份文本，保留内部兼容标识。
- 同步开发与打包运行时补丁，补齐市场报告 RAG Skill 和章节工作流的运行时文件。
- 将 market-report-rag 纳入预置用户自定义 SKILL，支持新安装和独立档案的聊天技能选择；保留已有用户自定义内容。

## 验证与版本

- 补充模型路由、协议隔离、兜底分类、取消请求、提示词迁移和打包补丁回归测试。
- 同步架构文档与版本号至 0.7.39，以触发 release 分支的自动打包。
