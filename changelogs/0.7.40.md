# v0.7.40 发布说明

本次发布扩展公司内部知识库报告能力，并修复自定义 Skill、Milvus 新字段及离线运行时依赖的打包问题。

## 三类分析报告

- 将市场分析、人力资源分析和财务分析拆分为三个可独立选择的用户自定义 Skill。
- 三类报告共用受约束的章节编排状态机，并按报告类型选择各自章节、依赖关系和并行生成波次。
- 市场分析报告固定采用七章结构和约定表头；第二章的需求侧市场地图及目标客户优先级表均增加“公司名称”列。
- 保留 `market_report_workflow` 兼容入口，新增统一的 `analysis_report_workflow` 入口。

## RAG 与 Milvus 适配

- 检索继续固定使用 `my_skill_kb`，不允许模型切换到其他集合。
- 查询向量转换为 NumPy `float16`，匹配 `Float16Vector(1024)` 字段，并使用与 AUTOINDEX 一致的 `COSINE` 度量。
- 离线运行时安装并启动验证 `pymilvus` 和 `numpy`，避免打包版本调用到系统中的旧 Python。

## Skill 与运行时打包

- 三个报告 Skill 作为仓库维护的 `custom` 预置内容直接进入安装包，不再依赖用户打开 Skill 列表后动态复制。
- 默认档案和新建命名档案都会安装预置 Skill，同时保留用户已有的同名自定义内容。
- 删除旧的系统级同名市场报告 Skill，避免发现列表与会话激活加载到不同副本。

## AIHub 备用密钥

- GitHub Actions 从 `AIHUB_API_KEY` Secret 生成受管理的运行时环境文件，密钥不会写入源码和提交历史。
- 安装时仅在档案没有有效 `AIHUB_API_KEY` 时填充；已有用户配置优先，不会被员工自动配置覆盖。
- 缺少 Secret 时发布工作流会立即失败，避免生成不具备模型兜底能力的安装包。

## 验证与版本

- 通过 Node 主进程类型检查、37 个桌面端与打包测试、21 个 RAG 与报告编排测试以及 `lat check`。
- 版本号升级至 0.7.40，推送 release 分支后触发 GitHub Actions 自动打包。
