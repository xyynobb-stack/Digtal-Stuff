# v0.7.42 发布说明

本版本完善报告工作流、用户 Skill 展示和桌面会话体验，并修复运行时升级、长对话输入、会话标题及报告输出目录等问题。

## 报告与 Skill

- 人力资源与财务分析报告按章节依赖分波并行生成，避免逐章串行等待。
- 用户自定义 Skill 支持可选 `display_name` 中文展示名，英文目录名和第三方 Skill 保持兼容。
- Skill Creator 同步生成可选展示名，三类报告 Skill 补充中文名称和用户可见中文进度规则。

## 会话体验

- 折叠的思考与工具详情不再创建完整 DOM，输入框高度计算减少强制布局，改善长报告会话中的输入卡顿。
- Dashboard 标题事件接入前端会话缓存和侧边栏，避免报告任务长期显示临时的 Active session skills 标题。
- 会话标题同步增加代际与时序保护，避免初始化、恢复和实时事件互相覆盖。

## 输出目录

- Gateway 正式接收并校验前端传入的 `output_dir`，通过本轮临时系统上下文约束文件输出位置。
- 输出目录随后端排队消息和隔离计算进程逐轮传递，回合结束后恢复原上下文，避免并发串用目录。
- 未选择工作目录时继续输出到系统桌面；选择工作目录后遵循用户的桌面或工作目录选项。

## 运行时与打包

- 恢复轻量运行时启动探针，将 NumPy、PyMilvus 完整性检查移至 GitHub 构建阶段，缩短 Checking local install 等待时间。
- 开发环境与安装包统一应用输出目录、中文进度和自定义 Skill 更新逻辑。

## 验证

- TypeScript 类型检查、Dashboard 输出目录回归测试、离线运行时打包测试及 `lat check` 通过。
